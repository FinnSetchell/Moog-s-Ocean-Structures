## Moog's Ocean Structures

Ocean-themed structure pack for Minecraft, built on Moog's Structure Lib. Universal single-jar datapack-style mod: works on Fabric, Forge, NeoForge, and Quilt.

Requires [Moog's Structure Lib](https://modrinth.com/mod/moogs-structure-lib).
