### ABOUT

Moog's Ocean Structures brings life, fun, and variety to your Minecraft oceans! Dive to explore Atlantean ruins, ancient shipwrecks, ocean temples, and drifting rafts scattered across every water biome. Every structure is built with vanilla blocks and entities, so the mod feels right at home in any modpack and keeps the vanilla feel of the game.

This mod works for Forge, Fabric, and NeoForge. It can also be installed server-side only.

To see some of the structures, head to the [images tab](https://www.curseforge.com/minecraft/mc-mods/mos-moogs-ocean-structures/screenshots).

### CONFIG PACK

Every aspect of the mod is customizable using datapacks. Downloadable config packs are published on the [GitHub releases page](https://github.com/FinnSetchell/Moog-s-Ocean-Structures/releases).

For details on how to write and load config datapacks, see the [Moog's Structure Lib wiki](https://github.com/FinnSetchell/MoogsStructureLib/wiki).
